## Контрольные вопросы (task.md)
1. **Что такое JSON? Особенности.** Текстовый формат обмена данными «ключ–значение», похож на объекты JavaScript. Лёгкий для чтения человеком и парсинга машиной; поддерживает объекты, массивы, строки, числа, `true/false/null`. Не хранит методы и ссылки.
2. **Что такое AJAX? Особенности.** Подход к асинхронному обмену данными с сервером без полной перезагрузки страницы. Позволяет обновлять части UI, улучшает отклик; опирается на HTTP-запросы, обычно через `XMLHttpRequest` или `fetch`.
3. **Из чего состоит AJAX?** Набор технологий: объект для запросов (`XMLHttpRequest`/`fetch`), формат данных (JSON/XML/текст), DOM для обновления страницы, иногда доп. утилиты (Promise, события) и серверная часть, возвращающая данные.
4. **Что такое XMLHttpRequest? Когда используется? Особенности.** Встроенный объект браузера для отправки HTTP-запросов из JS. Используется для AJAX: задаём метод/URL, слушаем события, читаем `response`. Особенности: колбэки событий, поддержка `responseType='json'`, работа по тому же происхождению (или с CORS), прогресс-запросы.
5. **Что такое CORS? Примеры.** Механизм, позволяющий браузеру обращаться к ресурсам другого домена при наличии разрешающих заголовков. Сервер отвечает заголовками `Access-Control-Allow-Origin`, `Allow-Methods`, `Allow-Headers`. Пример: фронтенд на `example.com` запрашивает API на `api.example.org`, сервер должен вернуть `Access-Control-Allow-Origin: https://example.com` (или `*` для публичных данных).

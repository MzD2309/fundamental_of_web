## 🛠️ Рекомендации к структуре программы

[cite_start]Данное задание является классическим получением данных из БД с помощью PHP[cite: 21]. [cite_start]Для работы с БД можно использовать **OpenServer** и **phpMyAdmin** для создания и управления базами данных[cite: 22].

### 1\. Подключение к БД

[cite_start]В первой странице можно провести подключение к БД[cite: 23]. [cite_start]Для этого необходимо указать адрес, имя пользователя, пароль и название самой базы данных[cite: 24]. [cite_start]Подключение осуществляется с помощью `mysqli()`[cite: 25].

**Листинг 1: Код подключения (`db.php`)**

```php
<?php
define('DB_HOST', 'localhost'); //Адрес
define('DB_USER', 'root'); //Имя пользователя
define('DB_PASSWORD', 'QweRtY'); //Пароль
define('DB_NAME', 'lab5_data'); //Имя БД
$mysql = new mysqli(DB_HOST,DB_USER,DB_PASSWORD,DB_NAME);
?>
```

[cite_start]Для того чтобы подключить этот код к документу со страницей, необходимо использовать команду `include`[cite: 36].

### 2\. Получение данных и вывод на страницу

[cite_start]После подключения нужно сделать запрос в БД и получить данные с помощью `mysqli_query()`[cite: 37].

**Листинг 2: Запрос к БД**

```php
<?php
include "db.php";
$result = mysqli_query($mysql, "SELECT * FROM `images`");
?>
```

[cite_start]Для вывода картинок необходимо сначала добавить сами картинки в корневую папку проекта[cite: 45].

[cite_start]Затем с помощью PHP-кода добавляется цикл, который получает доступ к содержимому таблицы в БД с помощью `mysqli_fetch_assoc()`, в который указывается ранее созданное подключение и запрос к таблице[cite: 46].

[cite_start]Чтобы заполнить данные с помощью HTML-кода, необходимо разграничить его с PHP[cite: 47]. [cite_start]В тегах, где указывается название изображения и путь к нему, нужно указать два вхождения PHP-кода с названием столбца таблицы в БД[cite: 48].

**Листинг 3: Цикл вывода картинок (пример)**

```php
<div class="box">
<?php
while($name = mysqli_fetch_assoc($result)){
?>
<div class="filters__img">
<img  title="<?php echo $name['name'];?>" src="/Data/img/<?php echo $name['img'];?>" />
</div>
<?php
}
?>
</div>
```

### 3\. Добавление данных в БД

[cite_start]Добавление данных можно реализовать с помощью **формы**[cite: 63]. [cite_start]Данные должны передаваться на другую страницу и уже оттуда добавляться в базу данных[cite: 64].

[cite_start]Для выполнения этой операции используется команда **`INSERT`** в качестве запроса к БД и команда **`query`** для обращения к БД[cite: 65].

[cite_start]Страница, на которую будет осуществляться переход, должна быть выполнена в стиле главной страницы[cite: 66]. [cite_start]Также необходимо выводить сообщение об успешном занесении данных и кнопку для возвращения на главную страницу[cite: 66].

### [cite_start]💻 РЕКОМЕНДАЦИИ К СТРУКТУРЕ ПРОГРАММЫ [cite: 14]
[cite_start]В данной лабораторной работе вам нужно доработать шаблон (см. файлы) страницы, загружающей записи посредством **AJAX**[cite: 15]. [cite_start]Задание состоит из двух частей[cite: 15].

#### [cite_start]Часть 1 [cite: 16]
[cite_start]На странице есть форма для поиска записей[cite: 17]. [cite_start]Вам нужно доработать скрипт `main.js` таким образом, чтобы эта форма заработала[cite: 17].
[cite_start]Чтобы осуществить поиск записей по запросу, нужно добавить параметр **q** к запросу на сервер[cite: 18].

#### [cite_start]Часть 2 [cite: 19]
[cite_start]После реализации поиска добавьте на страницу функционал **автодополнения запроса** пользователя[cite: 20].

* [cite_start]После начала ввода запроса пользователем ему должны отображаться варианты возможных запросов, которые начинаются с введённых пользователем символов[cite: 21].
    * Например, если пользователь введёт "m", ему могут быть предложены варианты "milk", "month", и т. [cite_start]д.[cite: 22].
    * [cite_start]Варианты автодополнения система генерирует автоматически на основе анализа истории запросов пользователей[cite: 23].
* [cite_start]Чтобы получить варианты автодополнения, необходимо выполнить запрос по указанному выше адресу (`http://cat-facts-api.std-900.ist.mospolytech.ru/autocomplete`) и передать в запросе параметр **q** -- текст поискового запроса, который на данный момент успел ввести пользователь[cite: 24].
* [cite_start]В ответ система пришлёт массив (в формате **JSON**) из 10 (или менее) наиболее популярных запросов, соответствующих указанному критерию[cite: 25].
* [cite_start]Для отображение возможных вариантов пользователю вам необходимо под полем ввода запроса добавить **выпадающий список**, как, например, это сделано в популярных поисковых системах (Google, Yandex, и др.)[cite: 26].
* [cite_start]Оформление списка остаётся на ваше усмотрение[cite: 27].
* [cite_start]При клике пользователя по одному из предложенных вариантов его значение должно быть подставлено в поле ввода запроса, а выпадающий список должен быть скрыт[cite: 28].

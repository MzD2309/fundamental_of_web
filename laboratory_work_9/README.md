## Описание проекта

Лабораторная работа №9 по дисциплине «Основы веб‑программирования»: табулирование значений кусочно-заданной функции (вариант 10) на языке PHP с выводом результатов разными способами в HTML-странице.

## Структура файлов

- **index.php**: основная HTML‑страница с внедрённым PHP‑кодом.
- **styles.css**: стили оформления страницы (шапка, основной блок, таблица, списки, блочная верстка, фиксированный подвал).
- **task.md**: текст задания (для преподавателя/проверки, в работу не подключается).

## Логика работы index.php

### 1. HTML‑каркас

- В начале файла объявлен стандартный HTML5-документ с языком `ru`.
- В `<head>`:
  - `meta charset="UTF-8"` — кодировка UTF‑8.
  - `<title>` — содержит номер работы, вариант, ФИО и группу.
  - Подключается файл стилей `styles.css`.
- В `<body>`:
  - `<header>` — шапка с информацией о лабораторной работе и студенте.
  - `<main>` — зона, внутри которой выполняется весь PHP‑код и выводятся результаты.
  - `<footer>` — фиксированный подвал с текстовым названием выбранного типа верстки.

### 2. Инициализация переменных в PHP

В начале PHP‑блока в `<main>` объявляются основные параметры табулирования:

- **$startX** — начальное значение аргумента \(x\) (сейчас `0`).
- **$stepsCount** — количество шагов табулирования (сейчас `15`).
- **$step** — величина шага аргумента \(x\) (сейчас `1`).
- **$minFuncLimit**, **$maxFuncLimit** — допустимый диапазон значений функции; если результат выходит за него, цикл прерывается.
- **$layoutType** — строковый параметр типа верстки: `'A'`, `'B'`, `'C'`, `'D'` или `'E'`.

Чтобы сменить тип вывода, достаточно изменить строку в `index.php`:

```php
$layoutType = 'C'; // A, B, C, D или E
```

### 3. Функция f_variant10(x) — вариант 10

Определена функция:

```php
function f_variant10($x)
{
    if ($x <= 10) {
        if ($x == 0) {
            return 'error';
        }
        $y = 3 / $x + $x / 3 - 5;
    } elseif ($x < 20) {
        $y = ($x - 7) * $x / 8;
    } else {
        $y = 3 * $x + 2;
    }

    return $y;
}
```

Это реализация кусочно-заданной функции варианта 10:

- \(f(x) = \frac{3}{x} + \frac{x}{3} - 5\), если \(x \le 10\);
- \(f(x) = \frac{(x - 7)x}{8}\), если \(10 < x < 20\);
- \(f(x) = 3x + 2\), если \(x \ge 20\).

### 4. Цикл табулирования и статистика

- Создаётся пустой массив **$rows** — сюда записываются все рассчитанные точки.
- В переменную **$currentX** заносится текущее значение аргумента (стартуем с `$startX`).
- Переменные **$sum**, **$minValue**, **$maxValue**, **$validCount** используются для подсчёта суммы, минимума, максимума и количества значений.

Основной цикл:

```php
for ($i = 0; $i < $stepsCount; $i++) {
    $x = $currentX;
    $y = f_variant10($x);

    if ($y < $minFuncLimit || $y > $maxFuncLimit) {
        break;
    }

    $rows[] = [
        'index' => $i + 1,
        'x' => $x,
        'y' => $y
    ];

    $sum += $y;
    $validCount++;

    if ($minValue === null || $y < $minValue) {
        $minValue = $y;
    }
    if ($maxValue === null || $y > $maxValue) {
        $maxValue = $y;
    }

    $currentX += $step;
}
```

После цикла вычисляется среднее арифметическое:

```php
$average = $validCount > 0 ? $sum / $validCount : null;
```

### 5. Округление и форматирование

Для вывода значений используется вспомогательная функция:

```php
function format_value($value)
{
    if ($value === null) {
        return '—';
    }
    return round($value, 3);
}
```

- Все числовые значения округляются до **3 знаков** после запятой.
- Для отсутствующих значений выводится тире `—`.

### 6. Выбор типа верстки и вывод результатов

Тип верстки выбирается по значению **$layoutType** с помощью конструкции `switch`:

- **'A'** — простой текст: каждая строка вида `f(x)=y`, разделённая тегом `<br>`.
- **'B'** — маркированный список: вывод внутри `<ul><li>...</li></ul>`.
- **'C'** — нумерованный список: вывод внутри `<ol><li>...</li></ol>`.
- **'D'** — таблица: создаётся `<table>` с колонками №, `x`, `f(x)` и рамкой `1px` чёрного цвета.
- **'E'** — блочная верстка: для каждой точки создаётся `<div>` с красной рамкой `2px` и внешним отступом (реализовано через класс `result-block` и контейнер `blocks-container`).

Название выбранного типа верстки для подвала выводится функцией:

```php
function layout_name($layoutType)
{
    switch ($layoutType) {
        case 'A':
            return 'Простой текст с разделителем &lt;br&gt;';
        case 'B':
            return 'Маркированный список (ul, li)';
        case 'C':
            return 'Нумерованный список (ol, li)';
        case 'D':
            return 'Таблица (табличная верстка)';
        case 'E':
            return 'Блочная верстка (div-блоки в ряд)';
        default:
            return 'Неизвестный тип верстки';
    }
}
```

В подвале (`<footer>`) вызывается `layout_name($layoutType)`, чтобы отобразить человекочитаемое название выбранного способа вывода.

### 7. Статистика

В конце в отдельном разделе «Статистика» выводятся:

- максимальное значение функции;
- минимальное значение функции;
- сумма всех значений;
- среднее арифметическое.

Все значения выводятся через `format_value(...)`, т.е. с округлением до 3 знаков.

## Как запустить проект

1. Установить PHP (если его нет в системе).
2. Поместить файлы `index.php` и `styles.css` в папку веб-сервера (например, `htdocs` для Apache) **или** запустить встроенный сервер PHP командой:
   ```bash
   php -S localhost:8000
   ```
   из папки проекта.
3. Открыть в браузере страницу:
   - `http://localhost/index.php` — если используете локальный сервер Apache/Nginx,
   - или `http://localhost:8000/index.php` — если используете встроенный сервер PHP.

## Ответы на контрольные вопросы

### 1. Что такое цикл и итерация?

- **Цикл** — это конструкция языка программирования, которая многократно выполняет один и тот же блок кода, пока выполняется некоторое условие (или задано фиксированное количество повторений).
- **Итерация** — это одно отдельное выполнение тела цикла (один проход по циклу).

### 2. Какие виды циклов бывают в PHP и чем они отличаются?

В PHP основные виды циклов:

- **`for`** — цикл с явной инициализацией счётчика, условием продолжения и обновлением счётчика; удобно использовать, когда известно количество повторений заранее.
- **`while`** — цикл с предусловием: перед каждой итерацией проверяется логическое условие, и если оно истинно, выполняется тело цикла.
- **`do-while`** — цикл с постусловием: тело цикла выполняется хотя бы один раз, а затем проверяется условие для повторения.
- **`foreach`** — специализированный цикл для перебора элементов массивов и объектов (удобен для работы с коллекциями).

### 3. В чём разница между `break` и `continue`?

- **`break`** — немедленно прерывает выполнение текущего цикла (или `switch`), управление передаётся на первую строку после цикла/конструкции `switch`.
- **`continue`** — прекращает текущую итерацию цикла и сразу переходит к проверке условия следующей итерации, не выполняя оставшийся код в теле цикла.

### 4. Какой тип данных определяет условие?

Условие в управляющих конструкциях (`if`, `while`, `for`, `do-while`, `switch`) в конечном итоге интерпретируется как **логический тип** (`boolean`), то есть приводится к `true` или `false` по правилам приведения типов PHP.

### 5. Как в PHP реализовать округление и конструкцию выбора?

- **Округление** выполняется с помощью функции `round`:
  ```php
  $result = round($value, 3); // округление числа $value до 3 знаков после запятой
  ```
- **Конструкция выбора** реализуется с помощью `switch`:
  ```php
  switch ($x) {
      case 0:
          // действия, если $x == 0
          break;
      case 1:
          // действия, если $x == 1
          break;
      default:
          // действия во всех остальных случаях
          break;
  }
  ```

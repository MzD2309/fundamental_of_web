# Лабораторная работа №6: Основы JavaScript

## Описание

Одна веб-страница демонстрирует работу пяти функций на JavaScript:

1. `pow(x, n)` — возведение в степень без использования `**` и `Math.pow()`.
2. `gcd(a, b)` — нахождение наибольшего общего делителя двух неотрицательных чисел.
3. `minDigit(x)` — поиск наименьшей цифры целого неотрицательного числа.
4. `pluralizeRecords(n)` — правильная форма фразы «было найдено n записей» на русском языке.
5. `fibb(n)` — n‑е число Фибоначчи (0 ≤ n ≤ 1000).

Каждой функции соответствует свой блок с полями ввода, кнопкой и областью для вывода результата.

## Структура проекта

```
laboratory_work_6/
```

## Как запустить

1. Поместите папку `laboratory_work_6` в корень вашего локального веб-сервера (например, OpenServer).
2. Запустите веб-сервер.
3. Откройте в браузере адрес вида:
   - `http://localhost/laboratory_work_6/index.html`

Страница загрузится, и вы сможете тестировать функции через форму.

## Реализованные функции

### 1. `pow(x, n)`

- Принимает числа `x` и `n`.
- `n` должно быть натуральным (`n >= 1`).
- Возвращает `x`, умноженное на себя `n` раз в цикле.
- Не использует `**` и `Math.pow()`.

### 2. `gcd(a, b)`

- Принимает целые неотрицательные числа `a` и `b`.
- Используется алгоритм Евклида.
- В случае `gcd(0, 0)` возвращается `0`.

### 3. `minDigit(x)`

- Принимает целое неотрицательное число `x`.
- Преобразует число в строку, затем в массив цифр.
- Находит минимальную цифру перебором.

### 4. `pluralizeRecords(n)`

- Принимает целое неотрицательное число `n`.
- Вычисляет правильную форму слова «запись» по русским правилам `one/few/many`:
  - `1 запись`
  - `2,3,4 записи`
  - `0, 5–20, 25, 111 и т.п. записей`
- Возвращает строку вида:
  - `"В результате выполнения запроса было найдено n записей"` (с нужной формой).

### 5. `fibb(n)`

- Принимает целое `n` в диапазоне `0 ≤ n ≤ 1000`.
- Использует итеративный алгоритм: на каждом шаге хранит только два предыдущих значения.
- Для точности вычислений использует тип `BigInt`.
- Возвращает `BigInt`; при выводе на страницу приводится к строке.

## Дополнительное задание

- Для каждой функции реализован ввод аргументов со страницы:
  - Поля `<input type="number">` для значений `x`, `n`, `a`, `b` и т.д.
  - Кнопки для запуска соответствующей функции.
- После нажатия кнопки производится чтение значений из полей, вызов функции и вывод результата в блоке под формой.
- Ошибки (например, неверный диапазон/тип аргумента) отображаются в выделенном стиле.

### 📝 ДОПОЛНИТЕЛЬНЫЕ ТРЕБОВАНИЯ К РАБОТЕ

1.  **Структура программы:**

      * [cite\_start]Результат лабораторной работы — одна **HTML-страница** — `header.html`[cite: 12].
      * [cite\_start]Вывод формы, обработка данных выполняется в файле `index.php`[cite: 12].
      * [cite\_start]Обработка ответа и вывод реализованы в другом файле программы - `home.php`[cite: 13].

2.  **Элементы формы (на странице при первой загрузке):**

      * **Однострочные поля для ввода текста:**
          * [cite\_start]ФИО [cite: 15, 16]
          * [cite\_start]Ваш е-майл [cite: 17] (должен быть установлен **placeholder**) [cite\_start][cite: 30]
      * **Многострочные поля для ввода текста:**
          * [cite\_start]сообщение [cite: 18, 19]
      * [cite\_start]**Селектор** (Тема обращения) со следующими опциями[cite: 20, 30]:
          * [cite\_start]Предложение [cite: 21]
          * [cite\_start]Жалоба [cite: 22]
      * **Флажок:**
          * [cite\_start]Даю согласие на обработку данных [cite: 23, 24] (изначально **не отмечен**) [cite\_start][cite: 30]
      * **Две радио-кнопки:**
          * [cite\_start]Реклама из интернета [cite: 25, 26]
          * [cite\_start]Рассказали друзья [cite: 27]
      * [cite\_start]**Выбор файла** [cite: 29]
      * [cite\_start]**Кнопка «отправить»** [cite: 28]

3.  **Оформление формы:**

      * [cite\_start]Все элементы формы должны быть **сгруппированы**[cite: 31].
      * [cite\_start]Все элементы (кроме флажка и кнопки) должны быть **выровнены по левому краю** и быть **одинакового размера**[cite: 32].
      * [cite\_start]**Подписи** к элементам должны располагаться **слева** от них[cite: 33].

4.  **Страница ответа (`home.php`):**

      * [cite\_start]Загружается при нажатии кнопки "Отправить"[cite: 34].
      * Выводит ответ со следующими данными:
          * [cite\_start]ФИО [cite: 35]
          * [cite\_start]Текст обращения [cite: 36]
          * [cite\_start]Название прикрепленного файла, если он был прикреплен [cite: 37]
      * [cite\_start]Содержит **Кнопку «Заполнить снова»**[cite: 38].

5.  **Повторное заполнение:**

      * [cite\_start]При переходе по кнопке «Заполнить снова» вновь загружается форма обратной связи[cite: 39].
      * [cite\_start]Поля **"ФИО"** и **"Email"** должны быть заполнены ранее введенными значениями[cite: 40].
      * [cite\_start]Должна быть **выбрана ранее отмеченная радио-кнопка**[cite: 40].

### 🛠️ РЕКОМЕНДАЦИИ К СТРУКТУРЕ ПРОГРАММЫ

[cite\_start]Представленное задание является классическим обработчиком данных формы[cite: 42].

#### 1\. Вынесение повторяющихся элементов (header.html)

[cite\_start]Так как используются две страницы (`index.php` и `home.php`), повторяющиеся элементы кода (объявление типа документа, блок `head`, структурный элемент `header`) выносятся в отдельный файл `header.html` и подключаются с помощью `include`[cite: 43, 44, 45].

**Листинг 1** \`\`\`html

\<\!DOCTYPE html\>

\<html lang="en"\>
\<head\>
\<meta charset="UTF-8"\>
\<meta http-equiv="X-UA-Compatible" content="IE=edge"\>
\<meta name="viewport" content="width=device-width, initial-scale=1.0"\>
\<title\>Форма обратной связи\</title\>
\<link rel="stylesheet" href="styles/style.css"\>
\</head\>
\<body\>
\<header\>
\<img src = "img\\Mospolytech\_logo.jpg"\>
\</header\>
[cite\_start]\`\`\` [cite: 46-61]

**Листинг 2 (Подключение)**

````php
<?php
include 'header.html';
?>
[cite_start]``` [cite: 63-68]

#### 2. Передача данных и повторное заполнение

* [cite_start]Данные формы будут размещены в массиве **`$_POST`**, так как передается большой массив данных (включая многострочный текст) (**POST-форма**)[cite: 86, 87].
* [cite_start]Признак заполнения формы — **наличие элементов с именами тегов формы** в массиве `$_POST` или `$_GET`[cite: 69, 88].
* [cite_start]Кнопка **«Заполнить снова»** формируется в виде ссылки с передачей соответствующих **GET-параметров** для повторного заполнения полей ФИО, email и радио-кнопки[cite: 73, 74].
* [cite_start]Для повторного заполнения форма проверяет существование указанных ключей в массиве **`$_GET`** и выводит их как значения полей, если они есть[cite: 75].

**Листинг 3 (Получение GET-параметров для повторного заполнения)**
```php
<?php
if(isset($_GET['name'])){
$name=$_GET['name'];
$email=$_GET['email'];
$source=$_GET['source'];
}
?>
[cite_start]``` [cite: 78-85]

**Листинг 4 (Пример невидимого поля для идентификации формы)**
```html
<input type="hidden" name="user_id" value="6">
[cite_start]``` [cite: 93-96]

#### 3. Обработка данных (`home.php`)

* [cite_start]**Проверка типа обращения:** На основе переданного значения селектора (`$_POST['category']`), с помощью условных операторов выводится соответствующий ответ[cite: 97, 98].

**Листинг 5 (Обработка типа обращения)**
```php
echo '<p> Здравствуйте,'.$_POST['name'].'</p>'; //выводим ФИО
if ($_POST['category'] == 'propose'){ //проверяем тип обращения
echo '<p>Спасибо за ваше предложение:</p>';
echo '<textarea>'.$_POST['message'].'</textarea>';//вывод текста сообщения
}else{
echo '<p>Мы рассмотрим Вашу жалобу:</p>';
echo '<textarea>'.$_POST['message'].'</textarea>';
}
[cite_start]``` [cite: 100-109, 101]

* [cite_start]**Поиск прикрепленного файла:** Если в массиве `$_POST` найдено непустое значение по ключу элемента вложения, выводится сообщение с названием файла[cite: 110].

**Листинг 6 (Обработка прикрепленного файла)**
```php
if (isset($_POST['attachment']) & $_POST['attachment'] != '') echo 'Вы приложили следующий файл: '.$_POST['attachment'];
[cite_start]``` [cite: 114-116]

* [cite_start]**Кнопка «Заполнить снова»:** Формируется HTML-код ссылки с передачей параметров `name`, `email` и `source` через **GET-параметры** для предварительного заполнения формы[cite: 117, 120].

**Листинг 7 (Кнопка «Заполнить снова»)**
```php
echo '<a class="btn" href="index.php?N='.$_POST['name'].'&E='.$_POST['email'].'&S='.$_POST['source'].'">Заполнить снова</a>';
[cite_start]``` [cite: 119-121]

## 💻 Основные Задания

[cite_start]Результатом работы должна быть веб-страница, на которой представлены результаты работы JavaScript, встроенного в код[cite: 10]. [cite_start]Данные должны содержать функции, которые выполняют следующие задачи[cite: 11]:

### [cite_start]1. Возведение в степень [cite: 12]

Напишите функцию `pow(x, n)`, которая:
* [cite_start]Возвращает $x$ в степени $n$[cite: 12].
* [cite_start]Умножает $x$ на себя $n$ раз и возвращает результат[cite: 13].
* [cite_start]**Обязана** поддерживать только натуральные значения $n$[cite: 13].
* [cite_start]**Встроенную операцию возведения в степень (`**` или `Math.pow()`) использовать нельзя**[cite: 14].

### [cite_start]2. Нахождение Наибольшего Общего Делителя (НОД) [cite: 15]

[cite_start]Напишите функцию `gcd(a, b)`, которая возвращает $x$ — **наибольший общий делитель** двух неотрицательных чисел $a$ и $b$[cite: 15].

### [cite_start]3. Наименьшая цифра числа [cite: 16]

[cite_start]Напишите функцию `minDigit(x)`, которая возвращает **наименьшую цифру** целого неотрицательного числа $x$[cite: 16].

> **💡 Рекомендация:** Для реализации этого кода можно перевести число в строку, после чего разделить его с помощью функции `split()`. [cite_start]Затем строковый массив перевести в числовой и уже в нем искать наименьшее число[cite: 25, 26].

### [cite_start]4. Плюрализация (Pluralization) [cite: 17, 18]

Требуется написать функцию `pluralizeRecords(n)`, которая для любого целого неотрицательного значения $n$ вернёт строку:

> `"В результате выполнения запроса было найдено n записей"`

[cite_start]В этой строке для слова **"записей"** должна быть образована правильная форма множественного числа, в зависимости от конкретного значения $n$ (например: 1 запись, 2 записи, 5 записей)[cite: 19, 20].

> [cite_start]**💡 Рекомендация:** Выборку можно реализовать с помощью условного оператора, опираясь на правила для русского языка (`one`, `few` и `many`)[cite: 27].

### [cite_start]5. Числа Фибоначчи [cite: 21]

[cite_start]Реализуйте функцию `fibb(n)`, которая для любого целого неотрицательного числа $n \le 1000$ вернёт $n$-ое число из **последовательности Фибоначчи**[cite: 21].

> **💡 Рекомендация:** Можно написать цикл, который начнёт с 1 и 2, затем из них получит $fib(3)$ как их сумму, затем $fib(4)$ как сумму предыдущих значений, и так далее, до финального результата. [cite_start]На каждом шаге нужно помнить только значения двух предыдущих чисел последовательности[cite: 28, 29].

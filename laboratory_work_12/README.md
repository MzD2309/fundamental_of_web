# Лабораторная работа №12  
**Тема:** Bootstrap. Вёрстка адаптивной целевой страницы (landing page)

## Описание проекта
Проект представляет собой одностраничный адаптивный лендинг для условного стартапа **StartupX**.  
Страница содержит три обязательных блока:
- **Hero-секция** — название проекта, краткое описание и иллюстрация.
- **Преимущества** — карточки с основными плюсами сервиса.
- **Контакты** — блок с контактной информацией и формой обратной связи.

Верстка выполнена с использованием **Bootstrap 5**, что обеспечивает корректное отображение страницы на ПК, планшетах и смартфонах.

## Структура проекта
- `index.html` — основная HTML-страница лендинга:
  - Подключение Bootstrap 5 через CDN (`<link>` + JS bundle).
  - Подключение иконок Font Awesome через CDN.
  - Фиксированная навигационная панель `navbar` (переход по якорям к блокам).
  - Блок `hero` (шапка) с сеткой Bootstrap (`row`, `col-12 col-lg-6`) и адаптивным изображением `img-fluid`.
  - Блок преимуществ (`cards` на Bootstrap) в сетке `col-12 col-md-6 col-lg-4`.
  - Блок контактов с контактами и формой (`form-control`, `form-select`, `form-check`).
  - Адаптивный подвал `footer`.
- `task.md` — текст задания (исходное ТЗ лабораторной).

Дополнительных CSS/JS-файлов нет: всё оформлено с помощью Bootstrap и небольшого встроенного стиля в `<style>`.

## Использование адаптивности Bootstrap в проекте
- Указан мета-тег для корректного масштабирования на мобильных устройствах:
  ```html
  <meta name="viewport" content="width=device-width, initial-scale=1">
  ```
- Для сетки и колонок применяются классы:
  - `col-12` — занимает всю ширину на мобильных устройствах,
  - `col-md-6` — две колонки на средних экранах,
  - `col-lg-4`, `col-lg-6` — три/две колонки на больших экранах.
- Навигация использует адаптивный `navbar`:
  - `navbar-expand-lg` — развёрнутое меню на больших экранах,
  - на малых экранах меню сворачивается в кнопку-«гамбургер».
- Изображения помечены классом `img-fluid`, чтобы автоматически подстраиваться под ширину контейнера.
- Отступы и размеры блоков регулируются утилитами Bootstrap (`py-5`, `py-lg-6`, `mb-3`, `gap-3` и т.п.).

## Ответы на контрольные вопросы

### 1. Что такое Bootstrap? Каковы его преимущества и возможности?
**Bootstrap** — это популярный CSS/JS-фреймворк для быстрой и адаптивной вёрстки сайтов.  
Преимущества:
- **Готовые компоненты** (кнопки, формы, карточки, навигация, модальные окна и т.д.).
- **Адаптивная сетка** для корректного отображения на разных устройствах.
- **Единый дизайн** за счёт встроенных стилей и переменных.
- **Большое сообщество и документация**, множество примеров.
Возможности:
- Построение сложных макетов с помощью сетки.
- Настройка отступов, цвета, типографики через набор утилит.
- Использование JavaScript-компонентов (модальные окна, dropdown, offcanvas и т.п.).

### 2. Как можно подключить Bootstrap к HTML-странице?
Есть два основных способа:
1. **Через CDN (как в этом проекте)** — подключение готовых файлов по URL:
   ```html
   <!-- CSS -->
   <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
   <!-- JS Bundle -->
   <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
   ```
   Плюсы: быстро, не нужно скачивать файлы.
2. **Локально** — скачать Bootstrap и подключить CSS/JS из локальных файлов:
   ```html
   <link rel="stylesheet" href="css/bootstrap.min.css">
   <script src="js/bootstrap.bundle.min.js"></script>
   ```
   Плюсы: проект не зависит от внешнего CDN.

### 3. Как можно конфигурировать настройки ширины элементов для разных устройств?
С помощью **сетки Bootstrap** и классов с брейкпоинтами:
- `col-` — для очень маленьких экранов (мобильные),
- `col-sm-` — ≥ 576px,
- `col-md-` — ≥ 768px,
- `col-lg-` — ≥ 992px,
- `col-xl-` — ≥ 1200px,
- `col-xxl-` — ≥ 1400px.

Пример:
```html
<div class="col-12 col-md-6 col-lg-4">...</div>
```
- На мобильных (`<768px`) элемент занимает всю ширину (`col-12`).
- На средних устройствах (`≥768px`) — половину (`col-md-6`).
- На больших (`≥992px`) — треть (`col-lg-4`).

Также можно управлять шириной и отображением через утилиты (`w-50`, `w-100`, `d-none d-md-block` и т.д.).

### 4. Какие «элементы» Bootstrap вы можете назвать? Как они влияют на отображение элементов страницы?
Ключевые элементы/компоненты Bootstrap:
- **Сетка (`container`, `row`, `col-*`)** — определяет расположение блоков на странице и их ширину на разных брейкпоинтах.
- **Компоненты**:
  - `navbar` — навигационная панель, может быть фиксированной, адаптивно сворачиваться.
  - `card` — карточка с заголовком, текстом, изображением.
  - `button` (`btn`, `btn-primary`, `btn-outline-secondary` и др.) — стилизованные кнопки.
  - `forms` (`form-control`, `form-check`, `form-select`) — стилизация форм и полей ввода.
  - `alerts`, `badges`, `modal`, `dropdown`, `collapse` и др.
- **Утилиты**:
  - отступы (`m-*`, `p-*`, `mt-3`, `py-5`),
  - выравнивание (`text-center`, `d-flex`, `justify-content-between`),
  - цвета (`text-primary`, `bg-dark`, `border-0`),
  - отображение (`d-none`, `d-md-block`).

Они влияют на:
- **Размер и расположение** элементов (через сетку и брейкпоинты).
- **Внешний вид** (цвета, отступы, тени, закругления).
- **Поведение** (адаптивность, сворачивание, модальные окна и т.д.).

## Построчное объяснение `index.html`

Ниже — комментарии к основным строкам и блокам файла `index.html` (по группам строк, как удобно объяснять на защите).

- **L1**: `<!DOCTYPE html>` — объявление типа документа, указывает, что используется HTML5.
- **L2**: `<html lang="ru">` — корневой элемент страницы, атрибут `lang="ru"` задаёт основной язык содержимого (русский).
- **L3–5**: блок `<head>` с мета‑информацией:
  - `<meta charset="UTF-8">` — кодировка UTF‑8, чтобы русские буквы отображались корректно.
  - `<meta name="viewport" content="width=device-width, initial-scale=1">` — включает адаптивную верстку на мобильных устройствах.
- **L6**: `<title>Водный кризис в Африке — Адаптивная целевая страница</title>` — заголовок во вкладке браузера.

- **L7–12**: `<link ... bootstrap.min.css>` — подключение CSS Bootstrap 5 по CDN:
  - даёт сетку (`container`, `row`, `col-*`), готовые компоненты (`navbar`, `card`, `btn`, `form-control`) и утилиты (`py-5`, `mt-5` и т.п.).
- **L13–20**: `<link ... font-awesome ...>` — подключение Font Awesome по CDN, чтобы использовать иконки с классами `fa-solid`, `fa-brands` и др.
- **L21–22**: закрываем `<head>`, открываем `<body>` — начинается видимая часть страницы.

### Навигация (navbar)

- **L23–38**: `<nav class="navbar navbar-expand-lg navbar-light bg-white border-bottom fixed-top shadow-sm">`
  - `navbar` — компонент навигации Bootstrap.
  - `navbar-expand-lg` — меню горизонтальное на `lg` и шире, на узких экранах сворачивается.
  - `fixed-top` — панель «прилипает» к верху окна при прокрутке.
  - `bg-white border-bottom shadow-sm` — белый фон, нижняя граница и лёгкая тень.
- **L89–93**: `<a class="navbar-brand d-flex align-items-center" href="#hero">`
  - бренд/логотип, клик ведёт к секции `id="hero"`.
  - внутри иконка капли (`<i class="fa-solid fa-droplet ...">`) и название `WaterAid Africa`.
- **L94–103**: `<button class="navbar-toggler"...>` — кнопка‑«гамбургер» для мобильного меню:
  - `data-bs-toggle="collapse"` + `data-bs-target="#mainNavbar"` — подключение компонента `collapse`.
- **L105–117**: `<div class="collapse navbar-collapse" id="mainNavbar">`
  - блок, который сворачивается/разворачивается.
  - `<ul class="navbar-nav ms-auto">` — список ссылок меню, `ms-auto` отталкивает его вправо.
  - каждый `<a class="nav-link" href="#...">` ведёт к нужной секции (`#hero`, `#benefits`, `#contacts`).

### Hero‑секция

- **L121**: `<section id="hero" class="mt-5 py-5 bg-white">`
  - `mt-5` — отступ сверху, чтобы контент не прилипал к фиксированному navbar.
  - `py-5` — вертикальные отступы.
  - `bg-white` — белый фон секции.
- **L122–123**: `<div class="container"><div class="row align-items-center g-5">`
  - `container` — центрирует контент и ограничивает ширину.
  - `row align-items-center g-5` — строка сетки с вертикальным выравниванием и промежутками между колонками.

**Левая колонка hero (текст):**

- **L124–152**: `<div class="col-12 col-lg-6">` — на мобильных занимает 12 колонок (всю ширину), на `lg` — 6 (половину).
  - `<span class="badge bg-primary-subtle text-primary fw-semibold mb-3">` — бейдж «Информационная кампания».
  - `<h1 class="display-5 fw-bold mb-3">` — главный заголовок о водном кризисе.
  - `<p class="lead text-muted mb-4">` — поясняющий текст, чуть крупнее обычного (`lead`) и серый (`text-muted`).
  - `<div class="d-flex flex-column flex-sm-row gap-3">` — контейнер для двух кнопок:
    - на совсем узких экранах — колонка (`flex-column`),
    - начиная с `sm` — строка (`flex-sm-row`),
    - `gap-3` — отступ между кнопками.
  - Первая кнопка:
    - `<a href="#contacts" class="btn btn-primary btn-lg px-4">Стать волонтёром</a>` — основное действие, ведёт к форме.
  - Вторая кнопка:
    - `<a href="#benefits" class="btn btn-outline-secondary btn-lg px-4">Узнать о проблеме</a>` — вторичное действие, ведёт к блоку преимуществ.
  - `<div class="d-flex flex-wrap gap-4 mt-4 text-muted small">` — блок с двумя «фактами»:
    - `flex-wrap` — переносит блоки на новую строку при нехватке ширины.
    - `small` — уменьшенный шрифт.
    - внутри по одному `div` с иконкой (`fa-users`, `fa-globe-africa`) и текстом.

**Правая колонка hero (картинка):**

- **L154–160**: `<div class="col-12 col-lg-6 text-center">`
  - на мобильных картинка идёт отдельной строкой, на больших экранах — справа от текста.
- `<img src="image.jpg" alt="..." class="img-fluid rounded-4 shadow">`
  - `img-fluid` — делает картинку адаптивной (max-width: 100%, height: auto).
  - `rounded-4` — скруглённые углы.
  - `shadow` — лёгкая тень.

- **L267**: `<section id="contacts" class="py-5 py-lg-6 bg-dark text-light">`
  - якорь `contacts`,
  - тёмный фон (`bg-dark`) и светлый текст (`text-light`),

**Левая колонка контактов:**

- `<div class="col-12 col-lg-5">` — ширина 12 колонок на мобильных и 5 из 12 на `lg`.

- `<p class="text-secondary mb-4">` — описание вариантов участия.
- `<ul class="list-unstyled text-secondary mb-4">` — список контактов:
  - каждый `<li class="mb-2 d-flex align-items-center">` содержит иконку (`fa-envelope`, `fa-phone`, `fa-location-dot`) и текст (почта, телефон, адрес).

- `<div class="col-12 col-lg-7">` — остальная часть ширины.

  - обёртка для формы с тёмным фоном, паддингами и тенями.

- `<div class="row g-3 mb-2">` — строка с двумя полями:
  - по одному полю в `col-12 col-md-6` → в столбик на мобильных, в ряд на `md`+.
  - поля: «Имя» и «E-mail» (`input type="text"/"email" class="form-control" required`).
- Блок выбора формата участия:
  - `<label for="topic" class="form-label">Формат участия</label>`
  - `<select id="topic" class="form-select" required>` со списком вариантов (`volunteer`, `donation`, `education`, `other`).
- Блок сообщения:
  - `<textarea id="message" class="form-control" rows="4" ... required></textarea>` — свободный текст от пользователя.
- Чекбокс:
  - `<div class="form-check mb-3">`
  - `<input class="form-check-input" type="checkbox" id="agreement" required>` — обязательное согласие на обработку данных.
  - `<label class="form-check-label small text-secondary" for="agreement">` — подпись и ссылка на «политику конфиденциальности».
- Кнопка отправки:
  - `<button type="submit" class="btn btn-primary btn-lg w-100">Отправить</button>` — большая синяя кнопка на всю ширину формы.

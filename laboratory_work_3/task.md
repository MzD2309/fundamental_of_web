## [cite\_start]ЦЕЛЬ РАБОТЫ [cite: 171]

[cite\_start]Основная задача языка РНР — **динамически формировать HTML-код страницы** или содержимое документов другого типа[cite: 174]. [cite\_start]При этом в РНР нет команд, которые бы добавляли на страницу таблицы, заголовки, блоки, формы или любые другие теги[cite: 175]. [cite\_start]Программный код выступает в роли HTML-верстальщика, который динамически, непосредственно перед загрузкой, верстает страницы сайта[cite: 178]. [cite\_start]Поэтому крайне важно знать и уметь самостоятельно работать со статическим НТМL-кодом[cite: 179].

| Характеристика | Требования к динамическому сайту |

## [cite\_start]РЕКОМЕНДАЦИИ К СТРУКТУРЕ ПРОГРАММЫ [cite: 198]

[cite\_start]Могут вызывать затруднения два вопроса: загрузка разных фотографий в зависимости от секунды и вывод пункта меню[cite: 201].

### Задача 1: Динамическая загрузка фотографий

[cite\_start]Пусть имеются две фотографии одинакового размера: `"fotos/foto1.jpg"` и `"fotos/foto2.jpg"`[cite: 203].

#### [cite\_start]Словесное описание алгоритма [cite: 203]

1.  [cite\_start]Определяем текущую секунду и сохраняем ее в переменной `\$s`[cite: 204].
2.  [cite\_start]Вычисляем остаток от деления переменной `\$s` на число 2 и сохраняем его в переменной `\$os`[cite: 205].
3.  [cite\_start]Если в переменной `\$os` хранится ноль, в переменную `\$name` записываем строку `"fotos/foto1.jpg"`[cite: 206].
4.  [cite\_start]Иначе в переменную `\$name` записываем строку `"fotos/foto2.jpg"`[cite: 207].
5.  [cite\_start]Формируем строку, содержащую тег `<img>` с вычисленным именем файла, и выводим ее в HTML-код браузера[cite: 208, 209].

#### [cite\_start]Листинг 1 (Прямой перевод) [cite: 218]

```php
<?php
// определяем текущую секунду
$s = date('s');
// вычисляем остаток от деления
$os = $s % 2; 

// если в переменной $os хранится ноль
if ($os == 0) {
    $name = 'fotos/foto1.jpg'; // сохраняем имя первого файла
} else {
    // иначе
    $name = 'fotos/foto2.jpg'; // сохраняем имя второго файла
}

// выводим сформированный HTML-код
echo '<img src="' . $name . '" alt="Меняющаяся фотография">'; 
?>
```

#### [cite\_start]Листинг 4 (Оптимизированный вариант) [cite: 248]

```php
<?php
// формируем НТМL-код и сразу его выводим
echo '<img src="fotos/foto'. (date('s') % 2 + 1) .'.jpg" alt="Меняющаяся фотография">';
?>
```

### Задача 2: Динамическое формирование пункта меню

[cite\_start]Пункт меню должен формироваться с помощью **двух фрагментов PHP-кода**[cite: 265].

#### [cite\_start]Листинг 7 (Разделение тега HTML на два PHP-скрипта) [cite: 277]

[cite\_start]Цель — РНР выводит **ТОЛЬКО** адрес и текст ссылки, а также ее класс[cite: 276].

```html
<a href="<?php
// начинаем первый РНР скрипт
echo 'page2.php';
?>" class="<?php
// начинаем второй РНР скрипт
echo 'selected menu">Вторая страница';
?></a>
```

#### [cite\_start]Листинг 8 (Универсальный код с переменными) [cite: 311]

[cite\_start]Универсальный код для всех пунктов меню[cite: 307].

```php
<?php
// начинаем первый РНР скрипт
$name = 'Вторая страница'; // переменная с текстом ссылки
$link = 'page2.php'; // переменная с адресом ссылки
$current_page = true; // переменная, определяющая активность пункта меню

// выводим адрес ссылки.
echo '<a href="' . $link . '"'; 

// начинаем второй РНР скрипт
if($current_page) {
    // если пункт меню активный
    echo ' class="selected menu"'; // выводим соответствующий класс
}

echo '>' . $name . '</a>'; // выводим текст ссылки и закрывающий тег
?>
```

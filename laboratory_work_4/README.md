# Лабораторная работа №4: Форма обратной связи

## 📋 Описание проекта

Это веб-приложение с формой обратной связи, которое позволяет пользователям отправлять сообщения, выбирать тип обращения (предложение или жалоба), прикреплять файлы и получать подтверждение о получении данных.

---

## 📁 Структура файлов

### 1. `header.html` - Общий шаблон страницы

**Что это?**  
Это файл с общими элементами HTML, которые повторяются на всех страницах.

**Зачем нужен?**  
Чтобы не дублировать один и тот же код (DOCTYPE, head, header) в каждом PHP-файле. Мы просто подключаем его через `include`.

**Что внутри:**
- `<!DOCTYPE html>` - объявление типа документа (говорит браузеру, что это HTML5)
- `<html lang="ru">` - корневой элемент с указанием языка
- `<head>` - служебная информация (кодировка, заголовок, подключение стилей)
- `<header>` - шапка сайта с заголовком

**Почему HTML, а не PHP?**  
Потому что это статический контент, который не меняется. PHP нужен только для динамических данных.

---

### 2. `index.php` - Страница с формой

**Что это?**  
Главная страница с формой обратной связи, куда пользователь вводит свои данные.

#### 🔍 Разбор кода по частям:

##### Часть 1: Получение GET-параметров (строки 1-15)

```php
$name = '';
$email = '';
$source = '';

if (isset($_GET['N'])) {
    $name = htmlspecialchars($_GET['N']);
}
```

**Что происходит?**
- Создаем пустые переменные для хранения данных
- `isset($_GET['N'])` - проверяем, есть ли в URL параметр `N` (например, `index.php?N=Иван`)
- Если есть - сохраняем его в переменную `$name`
- `htmlspecialchars()` - защита от XSS-атак (превращает `<script>` в безопасный текст)

**Зачем это нужно?**  
Когда пользователь нажимает "Заполнить снова" на странице ответа, данные передаются через URL (GET-параметры), и форма автоматически заполняется этими значениями.

##### Часть 2: Подключение header.html (строка 17)

```php
include 'header.html';
```

**Что это?**  
Вставляем содержимое файла `header.html` в текущую страницу. Это как копировать весь код из header.html сюда.

##### Часть 3: Форма (строки 21-74)

```html
<form action="home.php" method="POST" enctype="multipart/form-data">
```

**Разбор атрибутов:**
- `action="home.php"` - куда отправлять данные (на страницу home.php)
- `method="POST"` - способ отправки данных (скрыто, не видно в URL)
- `enctype="multipart/form-data"` - обязательно для загрузки файлов

**Почему POST, а не GET?**
- GET ограничен по размеру (максимум ~2000 символов)
- GET виден в URL (небезопасно для паролей и больших текстов)
- POST может передавать большие объемы данных и файлы

##### Элементы формы:

**1. Поле ФИО (строки 22-25):**
```html
<input type="text" id="name" name="name" value="<?php echo $name; ?>" required>
```
- `type="text"` - текстовое поле
- `name="name"` - имя поля (по нему PHP получает значение через `$_POST['name']`)
- `value="<?php echo $name; ?>"` - если есть значение из GET, подставляем его
- `required` - обязательное поле (браузер не даст отправить пустым)

**2. Поле Email (строки 27-30):**
```html
<input type="email" id="email" name="email" placeholder="example@mail.ru" value="<?php echo $email; ?>" required>
```
- `type="email"` - браузер автоматически проверяет формат email
- `placeholder` - подсказка внутри поля (исчезает при вводе)

**3. Сообщение (строки 32-35):**
```html
<textarea id="message" name="message" rows="5" required></textarea>
```
- `textarea` - многострочное поле для длинного текста
- `rows="5"` - начальная высота (5 строк)

**4. Селектор (строки 37-43):**
```html
<select id="category" name="category" required>
    <option value="propose">Предложение</option>
    <option value="complaint">Жалоба</option>
</select>
```
- `select` - выпадающий список
- `value="propose"` - значение, которое отправится в PHP (не то, что видит пользователь)
- Пользователь видит "Предложение", PHP получает "propose"

**5. Загрузка файла (строки 45-48):**
```html
<input type="file" id="attachment" name="attachment">
```
- `type="file"` - кнопка для выбора файла
- Файлы обрабатываются через `$_FILES`, а не `$_POST`

**6. Радио-кнопки (строки 50-62):**
```html
<input type="radio" name="source" value="internet" <?php echo ($source === 'internet') ? 'checked' : ''; ?> required>
```
- `type="radio"` - круглая кнопка (можно выбрать только одну из группы)
- `name="source"` - одинаковое имя для всех радио-кнопок в группе
- `value="internet"` - значение, которое отправится
- `<?php echo ($source === 'internet') ? 'checked' : ''; ?>` - если из GET пришло "internet", ставим галочку
- `required` - обязательно выбрать один вариант

**7. Чекбокс (строки 64-69):**
```html
<input type="checkbox" name="consent" value="yes" required>
```
- `type="checkbox"` - квадратная галочка
- Изначально не отмечен (нет атрибута `checked`)
- `required` - обязательно отметить для отправки

**8. Кнопка отправки (строки 71-73):**
```html
<button type="submit">Отправить</button>
```
- `type="submit"` - при нажатии отправляет форму на `home.php`

### 3. `home.php` - Страница ответа

**Что это?**  
Страница, которая показывается после отправки формы. Обрабатывает данные и выводит ответ пользователю.

#### 🔍 Разбор кода:

##### Часть 1: Подключение header (строка 2)

```php
include 'header.html';
```
Такое же, как в index.php - вставляем общий шаблон.

##### Часть 2: Проверка данных (строки 5-10)

```php
if (!isset($_POST['name']) || !isset($_POST['email']) || !isset($_POST['message']) || !isset($_POST['category'])) {
    echo '<p>Ошибка: не все обязательные поля заполнены.</p>';
    exit;
}
```

**Что происходит?**
- `isset($_POST['name'])` - проверяем, пришло ли поле "name"
- `!` - отрицание (если НЕ пришло)
- `||` - логическое ИЛИ (хотя бы одно условие истинно)
- Если хотя бы одно обязательное поле не заполнено - показываем ошибку и останавливаем выполнение (`exit`)

**Зачем это?**  
Защита от прямого обращения к home.php без отправки формы.

##### Часть 3: Обработка данных (строки 12-21)

```php
$name = htmlspecialchars($_POST['name']);
$message = htmlspecialchars($_POST['message']);
$category = $_POST['category'];
$source = isset($_POST['source']) ? $_POST['source'] : '';
```

**Что происходит?**
- `$_POST['name']` - получаем значение поля "name" из формы
- `htmlspecialchars()` - защита от XSS (превращает `<script>alert('hack')</script>` в безопасный текст)
- `isset($_POST['source']) ? $_POST['source'] : ''` - тернарный оператор:
  - Если `source` есть - берем его значение
  - Если нет - ставим пустую строку

**Почему не все через htmlspecialchars?**
- `$category` и `$source` - это значения из нашего списка (propose/complaint, internet/friends), мы их контролируем
- `$name` и `$message` - вводит пользователь, может быть вредоносный код

##### Часть 4: Обработка файла (строки 19-21)

```php
if (isset($_FILES['attachment']) && $_FILES['attachment']['error'] === UPLOAD_ERR_OK) {
    $attachment_name = htmlspecialchars($_FILES['attachment']['name']);
}
```

**Что происходит?**
- `$_FILES['attachment']` - массив с информацией о загруженном файле
- `['error'] === UPLOAD_ERR_OK` - проверяем, что загрузка прошла без ошибок
- `['name']` - имя файла (например, "document.pdf")
- Сохраняем только имя файла (не сам файл)

**Почему $_FILES, а не $_POST?**
- Файлы обрабатываются отдельно через специальный массив `$_FILES`
- В `$_POST` файлы не попадают

##### Часть 5: Вывод ответа (строки 26-44)

```php
<p>Здравствуйте, <?php echo $name; ?>!</p>

if ($category == 'propose') {
    echo '<p>Спасибо за ваше предложение:</p>';
} else {
    echo '<p>Мы рассмотрим Вашу жалобу:</p>';
}
```

**Что происходит?**
- Выводим приветствие с именем пользователя
- Проверяем тип обращения:
  - Если "propose" (предложение) - благодарим
  - Иначе (жалоба) - говорим, что рассмотрим

**Почему `==`, а не `===`?**
- `==` - нестрогое сравнение (может преобразовывать типы)
- `===` - строгое сравнение (типы должны совпадать)
- Здесь `==` достаточно, так как мы знаем, что придет строка

##### Часть 6: Кнопка "Заполнить снова" (строка 46)

```php
<a href="index.php?N=<?php echo urlencode($name); ?>&E=<?php echo urlencode($_POST['email']); ?>&S=<?php echo urlencode($source); ?>" class="btn">Заполнить снова</a>
```

**Что происходит?**
- Создаем ссылку на `index.php` с параметрами в URL
- `?N=...&E=...&S=...` - GET-параметры:
  - `N` - имя (name)
  - `E` - email
  - `S` - источник (source)
- `urlencode()` - кодирует специальные символы (пробелы, кириллицу) для безопасной передачи в URL
  - Например: "Иван Иванов" → "Иван%20Иванов"

**Зачем это?**  
При клике на "Заполнить снова" форма откроется с уже заполненными полями ФИО, Email и выбранной радио-кнопкой.

### 4. `styles.css` - Стили оформления

**Что это?**  
Файл с правилами оформления (цвета, размеры, расположение элементов).

#### 🔍 Основные части:

##### Общие стили (строки 1-13)

```css
* {
    box-sizing: border-box;
    margin: 0;
    padding: 0;
}
```

- `*` - селектор для всех элементов
- `box-sizing: border-box` - размер включает padding и border (удобнее считать)
- `margin: 0; padding: 0;` - убираем отступы по умолчанию

##### Форма (строки 43-74)

```css
.form-group {
    display: flex;
    flex-direction: row;
    align-items: center;
    gap: 15px;
}
```

**Что происходит?**
- `display: flex` - делаем контейнер гибким (flexbox)
- `flex-direction: row` - элементы в ряд (горизонтально)
- `align-items: center` - выравнивание по вертикали (по центру)
- `gap: 15px` - расстояние между элементами

**Почему flexbox?**  
Позволяет легко расположить label слева, а input справа, и все элементы будут одинакового размера.

```css
.form-group label {
    width: 180px;
    flex-shrink: 0;
}
```

- `width: 180px` - фиксированная ширина подписи
- `flex-shrink: 0` - не сжимается, всегда 180px

```css
.form-group input[type="text"],
.form-group input[type="email"],
.form-group select,
.form-group textarea {
    flex: 1;
    max-width: 400px;
}
```

- `flex: 1` - занимает все оставшееся пространство
- `max-width: 400px` - но не больше 400px (одинаковый размер для всех)

##### Радио-кнопки (строки 77-109)

```css
.radio-group {
    display: flex;
    flex-direction: row;
    align-items: flex-start;
}
```

- `flex-direction: row` - label и опции в ряд
- `align-items: flex-start` - выравнивание по верху (если опций много)

##### Кнопка отправки (строки 138-160)

```css
.submit-group > label {
    display: none;
}
```

- Скрываем label у кнопки (он не нужен)

```css
button[type="submit"]:hover {
    background-color: #555;
}
```

- `:hover` - стиль при наведении курсора
- Меняем цвет на более светлый

## 🔄 Как работает приложение (пошагово)

### Шаг 1: Пользователь открывает index.php
1. PHP проверяет, есть ли GET-параметры в URL
2. Если есть - заполняет переменные `$name`, `$email`, `$source`
3. Подключается `header.html`
4. Выводится форма с полями

### Шаг 2: Пользователь заполняет форму
1. Вводит ФИО, Email, сообщение
2. Выбирает тип обращения (предложение/жалоба)
3. Может прикрепить файл
4. Выбирает источник (радио-кнопка)
5. Ставит галочку согласия
6. Нажимает "Отправить"

### Шаг 3: Отправка данных
1. Браузер проверяет `required` поля
2. Если все заполнено - отправляет POST-запрос на `home.php`
3. Данные передаются в массиве `$_POST`
4. Файл (если есть) передается в массиве `$_FILES`

### Шаг 4: Обработка на home.php
1. Проверяется наличие обязательных полей
2. Данные обрабатываются и защищаются (`htmlspecialchars`)
3. Проверяется тип обращения
4. Проверяется наличие файла
5. Выводится ответ пользователю

### Шаг 5: Кнопка "Заполнить снова"
1. При клике создается ссылка с GET-параметрами
2. Параметры кодируются (`urlencode`)
3. Переход на `index.php` с параметрами в URL
4. Форма автоматически заполняется этими данными

## 🔐 Безопасность

### 1. Защита от XSS (Cross-Site Scripting)

```php
$name = htmlspecialchars($_POST['name']);
```

**Что это?**  
Превращает опасный код в безопасный текст.

**Пример:**
- Ввод: `<script>alert('hack')</script>`
- После обработки: `&lt;script&gt;alert('hack')&lt;/script&gt;`
- Браузер покажет как текст, а не выполнит как код

### 2. Проверка наличия данных

```php
if (!isset($_POST['name'])) {
    echo 'Ошибка';
    exit;
}
```

**Зачем?**  
Не даем обработать форму, если данные не пришли (например, прямой переход на home.php).

### 3. Кодирование URL

```php
urlencode($name)
```

**Зачем?**  
Специальные символы (пробелы, кириллица) кодируются для безопасной передачи в URL.

## 📊 Разница между GET и POST

| Параметр | GET | POST |
|----------|-----|------|
| **Где видны данные** | В URL (адресной строке) | В теле запроса (скрыто) |
| **Размер данных** | Ограничен (~2000 символов) | Большой (несколько МБ) |
| **Кэширование** | Да (браузер может сохранить) | Нет |
| **Безопасность** | Меньше (видно в истории) | Больше |
| **Использование** | Для простых данных, фильтров | Для форм, паролей, файлов |

**В нашем проекте:**
- **POST** - для отправки формы (большой текст, файлы)
- **GET** - для повторного заполнения (только имя, email, источник)

## 🎯 Ответы на контрольные вопросы

### 1. Что такое форма?
Форма - это набор элементов (поля, кнопки, списки) для ввода данных пользователем и отправки их на сервер.

### 2. Какие типы форм бывают?
- **GET-форма** - данные в URL, ограниченный размер
- **POST-форма** - данные в теле запроса, большой размер, можно файлы

### 3. В чем отличие POST- и GET-форм?
См. таблицу выше.

### 4. Какие элементы формы Вы знаете?
- `<input type="text">` - текстовое поле
- `<input type="email">` - поле для email
- `<input type="file">` - загрузка файла
- `<textarea>` - многострочное поле
- `<select>` - выпадающий список
- `<input type="radio">` - радио-кнопка (один из группы)
- `<input type="checkbox">` - чекбокс (галочка)
- `<button type="submit">` - кнопка отправки

### 5. Как передает свое значение каждый элемент формы в PHP-программу?
Через атрибут `name`:
- `<input name="email">` → `$_POST['email']`
- `<select name="category">` → `$_POST['category']`
- `<input type="file" name="file">` → `$_FILES['file']`

### 6. Сколько символов может максимально содержать строка, в которой буферизуется HTML-код?
В PHP по умолчанию нет жесткого ограничения, но рекомендуется не более нескольких МБ. Для больших данных используется потоковая обработка.

## 🛠️ Технические детали

### Массивы PHP для работы с формами:

**`$_POST`** - данные из POST-формы
```php
$_POST['name'] // значение поля с name="name"
```

**`$_GET`** - данные из URL (GET-параметры)
```php
$_GET['N'] // параметр из URL: index.php?N=Иван
```

**`$_FILES`** - загруженные файлы
```php
$_FILES['attachment']['name'] // имя файла
$_FILES['attachment']['error'] // код ошибки (0 = успех)
```

### Функции безопасности:

**`htmlspecialchars()`** - защита от XSS
```php
htmlspecialchars("<script>") // → "&lt;script&gt;"
```

**`urlencode()`** - кодирование для URL
```php
urlencode("Иван Иванов") // → "Иван%20Иванов"
```

**`isset()`** - проверка существования переменной
```php
isset($_POST['name']) // true, если поле есть
```

2. Результат работы 

Размещенный на Веб-сервере и доступный по протоколу HTTP документ (страница сайта) с результатами вычислений значений математической функции. 

---

3. Требования к оформлению (Шаблон HTML) 

Перед написанием PHP-кода необходимо подготовить статическую HTML-страницу со следующими характеристиками: 

* 
**Стандарты:** Использование HTML5 и CSS3. 


* 
**Валидация:** Прохождение проверки на [validator.w3.org](http://validator.w3.org/) без ошибок. 


* 
**Структура:** Наличие тегов `<header>`, `<main>` и `<footer>`. 


* **Шапка (Header):**
* Логотип университета. 


* ФИО студента, группа, номер лабораторной работы и варианта (также указать в теге `<title>`). 




* 
**Подвал (Footer):** Должен быть «приклеен» к низу экрана (фиксирован) и не реагировать на скроллинг. 


* **Оформление:**
* Цвета шапки и подвала должны отличаться от основного цвета страницы. 


* Стили прописаны в отдельном файле `styles.css`. 


* Основной блок (`<main>`): светло-серый фон, черный шрифт. 




* 
**Кроссбраузерность:** Корректное отображение во всех современных браузерах. 



---

4. Техническое задание на PHP-код 

Внутри тега `<main>` необходимо реализовать скрипт, который:

1. **Инициализирует переменные:**
* Начальное значение аргумента, количество шагов, величина шага. 


* Максимальное и минимальное значения функции (для остановки цикла). 


* Строковая переменная для типа верстки ('A', 'B', 'C', 'D', 'E'). 




2. 
**Выполняет расчеты:** Вычисляет значения функции согласно варианту. 


3. 
**Выводит результаты** в зависимости от типа верстки: 


* 
**'A':** Простой текст с разделителем `<br>` (вид: `f(x)=y`). 


* 
**'B':** Маркированный список (`<ul>`, `<li>`). 


* 
**'C':** Нумерованный список (`<ol>`, `<li>`). 


* 
**'D':** Таблица с колонками: № строки, аргумент, значение функции (рамка 1px, черная). 


* 
**'E':** Блочная верстка (`<div>`): блоки в ряд, красная рамка 2px, отступ 8px. 




4. 
**Статистика:** Вычисляет и выводит max, min, среднее арифметическое и сумму всех значений. 


5. 
**Подвал:** Выводит название выбранного типа верстки.

6. Справочная информация 

| Конструкция | Синтаксис |
| --- | --- |
| **Цикл for** | `for( $i=0; $i<100; $i++ ) { ... }` |
| **Цикл while** | `$x=0; while ($x<10) { ...; $x++; }` |
| **Цикл do-while** | `$x=0; do { ...; } while ($x++<10);` |
| **Оператор break** | Прекращает выполнение цикла. |
| **Оператор continue** | Прекращает текущую итерацию цикла. |
| **Switch** | `switch ($x) { case 0: ...; break; default: ...; }` |
| **Округление** | `round( $value, $precision );` |
